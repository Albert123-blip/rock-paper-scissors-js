# Rock Paper Scissors

A browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript. Pick rock, paper, or scissors and play against the computer while the game keeps track of both scores.

## How to Play

1. Click one of the three buttons: 👊 (rock), ✋ (paper), or ✌️ (scissors).
2. The computer picks its move at random.
3. The result is shown on screen:
   - **YOU WIN!** appears in green
   - **YOU LOSE!** appears in red
   - **IT'S A TIE** appears when both choices match
4. Keep playing and try to beat the computer's score.

## Game Rules

- Rock beats scissors
- Scissors beats paper
- Paper beats rock

## Features

- Random computer choice every round
- Shows both the player's and the computer's choice
- Colour-coded win and lose messages
- Running score for the player and the computer
- Button hover effect

## Getting Started

### Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Albert123-blip/rock-paper-scissors-js.git
   ```
2. Open the project folder:
   ```bash
   cd rock-paper-scissors-js
   ```
3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
